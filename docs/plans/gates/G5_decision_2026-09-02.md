## Context

G5 is the correspondence verification gate that authorizes external release preparation (WP9). This gate was added in v1.2 after the 2026-08-29 pilot revealed fail-open correspondence gates: the pilot released with 0 manifests and 105/109 equations missing, yet all gates reported "pass."

Per v1.2 program §5.7, before proceeding to external release:

> Correspondence gates must be fail-closed (block when thresholds violated), evidence-item emission must work (schema-compliant records), and assembly correspondence must meet ≥99% threshold.

This gate verifies the correspondence remediation work (WP7-WP8) addresses the 2026-08-29 pilot failure.
